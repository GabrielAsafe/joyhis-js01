# PCB Prefixes

| Prefix | Meaning |
|---|---|
|R|Resistor|
|C|Capacitor|
|L|Inductor|
|D|Diode|
|Q|Transistor/MOSFET|
|U|Integrated Circuit|
|X,Y|Crystal|
|SW|Switch|
|CN,J,CON|Connector|
|TP|Test Point|
|F|Fuse|
|FB|Ferrite Bead|
|LED|LED|
|BZ|Buzzer|

Each component should first be tested with power OFF unless measuring voltage.
