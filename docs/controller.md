# Vicont AQC03L

36V
350W
15A current limit

## Handlebar connector

Red  : +15V
Black: GND
Yellow: SW
Blue : TX
Green: RX

## Motor

Three phase wires.
Five Hall wires.

Evidence indicates UART communication between display and controller.

No analog throttle input was identified on the display harness.

## Replacement

Universal 36V 350W BLDC controller is a possible retrofit while keeping:
- Battery
- Motor
- Hall sensors
