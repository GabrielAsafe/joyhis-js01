# Joyhis JS01 / AOVOPRO / Vicont Reverse Engineering

## Goal
Open documentation for reverse engineering Joyhis JS01 / AOVOPRO scooters using the Vicont AQC03L controller.

## Confirmed hardware
- Scooter: Joyhis JS01
- Battery: 37V nominal (5.2Ah)
- Controller: Vicont AQC03L
- Motor: Front hub BLDC, Hall sensors
- Display PCB identified: AOVOPRO Display V2
- V4 PCB was visually the closest revision during comparison.
